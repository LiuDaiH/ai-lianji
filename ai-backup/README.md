# AI 能力的真实实现（备份区）

**这个目录不会被打包进小程序**（`project.config.json` 的 `packOptions.ignore` 排除了它）。

## 这里的文件

| 文件 | 说明 |
|---|---|
| `ai.js` | AI 能力完整实现：5 个能力 + 全链路降级 + 逐层诊断 |
| `ai-config.js` | 环境 ID / 模型名配置 |

## 为什么放这里

微信规定「**深度合成 - AI 问答**」服务类目**只对企业 / 个体户开放**，个人主体申请不了。
正式上线版如果带 AI 能力，审核会被要求补类目 → 直接驳回。

所以：**代码完整保留在这里，但不进小程序包。** 提交审核的包里是零 AI 痕迹的。

## 什么时候、怎么恢复

拿到「深度合成 - AI 问答」类目之后（需要先办个体工商户或企业主体），执行：

```
python tools/toggle-ai.py on
```

或者在**另一个终端**里跑：

```
python tools/toggle-ai.py status     # 看当前是哪一版
python tools/toggle-ai.py on         # 切回 AI 版（会自动校验依赖）
python tools/toggle-ai.py off        # 切回提交审核版
```

## 办类目的流程（备忘）

1. 办个体工商户（各省「一网通办」全程网办，执照基本免费）
2. 微信认证（企业主体，300 元/年）
3. 云开发控制台 → AI 板块 → 「获取算法合作协议」
   → 自动生成①腾讯云的算法备案截图 ②深度合成算法合作协议（**免自研备案**）
4. 公众平台 → 服务类目 → 添加「深度合成 > AI 问答」→ 上传上面两份材料
5. **类目审核通过后**，再跑 `toggle-ai.py on` 并提审 AI 版
   （顺序不能反，官方明确：类目没过就提代码，100% 驳回）

## 提审 AI 版前还要做的 3 件合规改造

- [ ] 所有 AI 输出处**全程固定展示**「AI 生成，仅供参考」（不能是角落小字或只弹一次）
- [ ] 用户输入 + AI 输出都接入 `wx.msgSecCheck` 内容安全过滤
- [ ] 隐私协议补充 AI 条款（内容由 AI 生成、数据处理方式、免责声明）
